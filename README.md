# Studio Norte

Sitio web corporativo de una sola página para Studio Norte, construido desde cero con HTML, CSS y JavaScript puro (Vanilla).

## Características
- **Diseño UI/UX Senior:** Paleta de colores editorial, tipografía premium y micro-interacciones.
- **Glassmorphism:** Efectos de cristal profesional en botones y tarjetas.
- **Dark / Light Mode:** Cambio de tema dinámico con persistencia (LocalStorage).
- **100% Responsive:** Adaptado para móviles, tablets y escritorio.
- **Scroll Animations:** Animaciones fluidas al hacer scroll.
- **Accesibilidad:** Respeto a `prefers-reduced-motion` y estados de `focus-visible`.

- `index.html`: Estructura semántica y contenido.
- `css/style.css`: Estilos, variables de tema y diseño responsive.
- `js/main.js`: Lógica de interacción, validación de formulario y modo oscuro.
